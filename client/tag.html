Tag Builder

Build the two kinds of tag QRSpool scans: a filament tag for a spool, and a slot tag for an AMS slot. Tag data updates as you type; copy it into a QR code generator, or write it straight to an NFC tag.

Filament Tag

Must match a Bambu Studio filament profile name, e.g. PLA Matte.
#
Pick a suggested or custom color with the swatch, or type/paste a 6-digit hex value.
Text embossed on the 3D printed tag. Leave blank to use the auto-generated label ().

OpenSpool 1.0 String

The QRSpool format. Put this in a QR code, or write it to an NFC tag as a plain text record.

OpenSpool JSON

OpenSpool tag contents. On an NFC tag this goes in an application/json record.

QRSpool URL

Opens this site with the filament data pre-loaded. Use this for NFC tags on phones without in-browser NFC support (i.e. anything that isn't Chrome on Android).

QR2STL Settings

Generates a printable 3D QR code. Open QR2STL, click Import/Export Settings at the top right, paste this into the Import box, and click Apply Settings.
